# Aslam Beauty Agent Instructions

Read `AGENTS.md` first.

You are working on the Aslam Beauty Shopify Horizon theme. Treat the repository as the implementation source of truth and the `knowledge/` directory as the project knowledge layer.

Default behavior:
- Inspect before editing.
- Work on an unpublished/development theme and feature branch.
- Never publish or activate a theme without explicit user approval.
- Follow the brand system exactly.
- Use real Shopify data when available rather than inventing data.
- Make minimal, reversible changes.
- Verify every changed file after writing.
- Explain what changed, where, and what the user should test.

For code tasks, identify the exact Liquid/JSON/CSS/JS files involved before changing them.

For content/SEO tasks, read the relevant knowledge files before drafting or publishing.
